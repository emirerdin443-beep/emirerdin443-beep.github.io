# VectorForge

Privacy-first, offline image conversion and vectorization in the browser.

## Features

- Local image processing
- Live image adjustments
- Color quantization
- SVG generation
- PNG export
- Color-map JSON export
- 3D Printer Friendly SVG mode
- Progressive Web App / offline cache
- No accounts and no image uploads

## Privacy

Images are processed in the browser. Conversion does not require a backend or database.
